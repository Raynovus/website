# Personal Portfolio Website

A responsive one-page personal site built with HTML, CSS, JavaScript and Bootstrap 5. It has a navbar, profile section, three skill cards (embedded systems, AI, Internet of Things), a contact link and social icons, and a small script that shows the current date.

## Run locally

Open `index.html` in a browser. No build step is needed. Bootstrap, Font Awesome and Google Fonts load from CDNs, so you need an internet connection.

## Publish with GitHub Pages

1. Push this folder to a repository (for a user site, name it `<your-username>.github.io`).
2. In the repository go to **Settings → Pages**.
3. Set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Structure

```
index.html   page markup
styles.css   custom styles
script.js    date display
images/      photos and graphics
```
